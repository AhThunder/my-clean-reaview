## 💡 왜 MyCleanReview인가요?

온라인 쇼핑을 할 때 우리는 수천 개의 별점 5점 리뷰를 넘기며 "**진짜 내 돈 주고 산 사람의 솔직한 단점은 없을까?**", "**끝없이 긴 통이미지 상세페이지를 다 읽지 않고 규격만 바로 알 수는 없을까?**"라는 피로감을 겪습니다. 특히 생성형 AI의 보급으로 정교해진 스팸 리뷰와 무분별한 체험단·협찬 후기는 소비자의 합리적인 판단을 더욱 흐리게 만듭니다.

**MyCleanReview**는 단순한 텍스트 요약을 넘어, **데이터 사전 정제(Pre-Filtering) · 비판적 관점의 AI 리뷰 분석 · 멀티모달 기반 상세페이지 실시간 Q&A**를 쇼핑 화면 위에서 끊김 없이 제공하는 올인원 쇼핑 어시스턴트입니다.

| 기존 온라인 쇼핑의 한계 | MyCleanReview의 해결 방식 |
| :--- | :--- |
| **심각한 5점 편향**: 상단 베스트 리뷰 대부분이 5점이라 치명적 결함 파악이 어려움 | **별점 비율 정밀 타겟팅**: 불만 집중(`1·2점 60%`) 등 원하는 별점 구간만 직접 추출·분석 |
| **협찬·도배 리뷰 왜곡**: 대가성 체험단 문구와 무의미한 이모지 남발 후기가 요약 품질을 저하시킴 | **3단계 기계식 사전 차단**: AI 분석 전 0.01초 만에 협찬·도배성 리뷰를 선제 격리 |
| **일방적 필터링의 한계**: 규칙 필터가 유용한 장문 후기까지 제외할 경우 확인 방법이 없음 | **제외 리뷰 선택 재요약**: 차단된 리뷰와 사유를 투명하게 확인하고 원하는 글만 체크해 재반영 |
| **이미지 기반 상세페이지**: 제품 스펙이 이미지로 되어 있어 <kbd>Ctrl</kbd>+<kbd>F</kbd> 검색이 불가능함 | **멀티모달 상품 Q&A 챗봇**: 상세 이미지를 비전 AI로 판독·캐싱하여 궁금한 사양에 1초 내 답변 |

### 사용자 중심의 디테일 경험
* **오탐 보완을 위한 선택적 재요약 (`Partial Re-summarize`)**: 사전 필터로 제외된 리뷰 목록과 차단 사유 태그(`협찬 문구`, `다수 이모지`)를 카드 형태로 열람하고, 참고 가치가 있는 리뷰만 개별 선택해 즉시 다시 요약할 수 있습니다.
* **페이지 이탈 없는 인페이지 드로어 UI**: 브라우저 상단 툴바를 찾을 필요 없이, 쿠팡 상품 화면 우측 하단에 표시되는 **실시간 플로팅 버튼** 하나로 슬라이드 분석 패널을 여닫을 수 있습니다.
* **중도 닫힘 걱정 없는 세션 자동 복원**: 실수로 패널 바깥을 눌러 창이 닫히더라도 동일 상품 페이지에서는 마지막 분석 결과가 로컬 스토리지에서 즉시 복원됩니다.
* **투명한 분석 원본 검증 (<kbd>F12</kbd> Console Audit)**: AI가 실제로 어떤 리뷰들을 읽고 결과를 도출했는지 직접 확인할 수 있도록 브라우저 개발자 도구(<kbd>F12</kbd>) 콘솔에 정제된 분석 대상 테이블(`console.table`)을 투명하게 출력합니다.

## 🚀 시작하기 (Getting Started)

### 1. 크롬 웹스토어에서 설치 (권장)
아래 링크에서 **[Chrome에 추가]** 버튼만 누르면 별도의 복잡한 설정 없이 바로 사용할 수 있습니다.

**[MyCleanReview 크롬 웹스토어 바로가기](https://chromewebstore.google.com/detail/mycleanreview/lopaoogbfbpopbejfindegpcnpdkncej?authuser=0&hl=ko)**

### 2. 기본 사용 방법
1. **쿠팡 상품 페이지 접속**: [쿠팡(coupang.com)](https://www.coupang.com/)에서 분석하고 싶은 상품 페이지로 이동합니다.
2. **위젯 실행**: 화면 우측 하단에 나타나는 **`리뷰 요약`** 플로팅 버튼을 클릭하거나 브라우저 우측 상단 확장 프로그램 아이콘을 클릭합니다.
3. **맞춤형 리뷰 요약 확인**:
   * 원하는 **분석 리뷰 수(10~30개)**, **별점 선정 비율(균형 / 불만 집중 / 직접 지정)**, **필터링 강도(1~3단)**를 선택하고 요약을 시작합니다.
   * 도출된 6개 핵심 키워드 칩을 클릭하여 키워드별 실구매자 반응을 비교하고, 하단의 **아쉬웠던 점 / 좋았던 점** 카드를 확인합니다.
4. **상품 챗봇(Q&A) 활용**:
   * 상단 탭에서 **`상품 챗봇 (Q&A)`**을 선택하면 상세페이지 이미지를 자동으로 분석합니다.
   * *"전자레인지 사용 가능한가요?"*, *"정확한 가로·세로 치수가 어떻게 되나요?"* 등 궁금한 점을 질문해 즉시 답변을 받아보세요.

## 🔧 엔지니어링

* **80~90% 이상 데이터 페이로드 경량화**: 무거운 원본 JSON 응답(작성자 프로필, 첨부 미디어 URL, 불필요한 중첩 객체 등)을 그대로 전송하지 않고 핵심 리뷰 본문(`content`)만 정밀 추출하여 네트워크 대역폭을 줄이고 **평균 3~5초 이내의 빠른 요약 응답 속도**를 구현했습니다.
* **1회 비전 분석 & 인메모리 캐싱 아키텍처**: 대화형 챗봇 이용 시 질문마다 고해상도 상세 이미지를 반복 전송하는 비효율을 없애기 위해, 상품당 최초 1회만 멀티모달 비전 모델로 공식 스펙을 텍스트화하여 메모리에 캐싱하고 후속 질문에는 **1초 내외로 즉각 응답**합니다.
* **엄격한 할루시네이션(거짓 답변) 방지 가드레일**: 상품 Q&A 챗봇은 오직 제조사 공식 상세페이지에서 추출된 팩트만을 근거로 답변하며, 상세설명에 명시되지 않은 내용은 임의로 추측하지 않고 명확히 부재 안내를 제공하도록 설계되었습니다.

## 🔒 개인정보 보호 및 보안

MyCleanReview는 **Privacy by Design** 원칙에 따라 설계되었습니다.
* **개인 식별 정보(PII) 수집 제로**: 이름, 계정 정보, 결제 내역, 웹 브라우징 기록 등 어떠한 개인정보도 수집하거나 추적하지 않습니다.
* **외부 자체 서버 무운영**: 모든 사용자 설정값과 분석 세션 캐시는 오직 **사용자의 로컬 브라우저(`chrome.storage.local`)** 내부에만 보관됩니다.
* **원격 코드 미사용**: 모든 실행 스크립트는 확장 프로그램 패키지 내부에 100% 번들링되어 안전하게 구동됩니다.

자세한 내용은 [개인정보 처리방침 (PRIVACY_POLICY.md)](./PRIVACY_POLICY.md)에서 확인하실 수 있습니다.
